# Inteligência Agêntica — O Ecossistema Hermes OS

Landing Page oficial de alta conversão para a comunidade e assinatura **Inteligência Agêntica**.

## 🚀 Sobre o Projeto
Landing page desenvolvida com foco em performance, acessibilidade e conversão para o ecossistema de automações e treinamentos agênticos.

- **Stack**: HTML5 semântico, Tailwind CSS (CDN), Lucide Icons, Vanilla JS.
- **Design System**: Dark High-Tech (Preto Obsidiana `#07070A`, Ciano Elétrico `#00E5FF`, Roxo Magenta `#D966FF` e Dourado Champanhe `#DFBA6B`).
- **Checkout**: Modal Lightbox integrado via Hotmart Widget (`checkoutMode=2`).
- **Performance & SEO**: Pontuação 100/100 em Acessibilidade e Boas Práticas, 0 layout shifts (CLS 0) com fallback font-face inline.

## 🛠️ Como Executar Localmente
Para testar a página localmente:

```bash
# Com Python 3
python -m http.server 3000

# Ou com Node.js / npx
npx serve .
```

Acesse em `http://localhost:3000`.
